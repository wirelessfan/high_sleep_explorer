# 发现小站：36 道题的理解与图解审校

用户反馈轻绳图解帮助 Sunny 理解，要求继续检查其他备考题。本轮覆盖发现小站全部 18 类、36 题（物理 14、数学 10、化学 12）。保留轻绳题已经明确的受力与加速度关系，改写其余 35 题解析，并核查 36 张 SVG。

## 结论与修改

没有发现需要更换正确选项的数值或公式错误，主要问题是图中关系不完整、图与本题变换不对应、适用条件交代不足。逐题按“看见什么关系 → 为什么这样 → 列式 → 检查边界”补充讲解。

| 题目 | 独立复核结果（第 1 / 第 2 题） | 图解与理解修订 |
| --- | --- | --- |
| rope | T=24 N、a=2 m/s² / 上30 N、下20 N | 保留不平衡轻绳图；有质量绳单独隔离，补自重10 N及下端受力方向 |
| pulley | T=20 N、自由端速率2倍 / T=36 N、自由端a=4 m/s² | 研究“负载+轻滑轮”，补两股向上T与向下mg；自由端与固定端分清；绳长约束单独说明 |
| friction | f=6 N反推力 / a=3可不滑、a=5不能 | 补完整静止箱子受力；向右摩擦带动物块；需求6/10 N与8 N上限分开，10 N不是实际静摩擦 |
| system | a=2 m/s²、接触力6 N / F=15可、F=25不可共同运动 | 整体与隔离B并列；叠放A、B补相反层间摩擦；超过上限不能沿用共同加速度 |
| elevator | N=400 N / N=720 N、mg=600 N | 把速度、加速度与乘客受力图分开，补N与mg，说明“失重/超重”不改变重力 |
| brake | 4 s停、6 s路程40 m / 最大接近35 m，初距须严格大于 | v-t分段画到停车后保持零；后车反应段、前后车差面积与最大接近时刻明确 |
| vt | 位移0 m、路程8 m / 位移3 m、路程5 m | 同一坐标映射，统一轴上绿正、轴下橙负；t=1 s变向与正加速度分清 |
| log-domain | a>1且a≠2、x>2 / 仅x=2 | 完整底数a−1与真数x−2分开；两真数条件取交集；配方说明乘积最大值 |
| log-base | 1<x<3 / 1/2<x≤2 | 通用示意横轴改为完整真数u，防止当作题目x；递减反向与端点检查补齐 |
| log-change | 2/(1+a) / 1 | 分式换底图，6=2×3；指数→倒数对数→同底相加的连接补清 |
| log-fixed | (3,3)、x>2 / (1,−2)、x>1/2 | 原图画原函数，现画本题函数族；曲线、渐近线、交点、坐标投影共用实际数学映射 |
| trig-sign | cos=−4/5、tan=−3/4 / −cos²α | 单位圆补投影和坐标符号；第二题补两个变换角所在象限，示意角不当作题设数值 |
| gas-volume | 水不是气态，不能套22.4 L/mol / 氧原子0.55Nₐ | 明确标准状况还需气体条件；O₂/O₃图解释1:3分子数比例及每分子原子数 |
| concentration | 最终溶液体积未知 / c(Cl⁻)=1 mol/L | 保留未知液面；两种溶液输入、Cl⁻的1倍/2倍与最终体积可加条件明确 |
| limiting | HCl限量、H₂=0.1 mol / H₂=0.2 mol，金属各自剩余不唯一 | 比n/系数的配方份额，完整配平方程式；总酸需求与实际量、总量可定而分配未定分清 |
| ionic | CaCO₃(s)+2H⁺→Ca²⁺+CO₂+H₂O / 沉淀0.075 mol、余OH⁻0.05 mol | 固体保留、旁观离子约去；沉淀与中和两条计量线，各自判断限量 |
| redox | 转移1 mol电子 / Fe³⁺0.06 mol、余Fe²⁺0.04 mol | 得失同一笔电子不相加；化合价账本不暗示微观机理；每mol粒子电子数明确 |
| periodic | Na、中子12 / O²⁻>F⁻>Na⁺>Mg²⁺ | 电子数→Z→中子数；等电子前提保留，定性大小随Z缩小，并注明不是实测比例 |
