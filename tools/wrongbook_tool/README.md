# 错题本录入工具（本地 Web 小工具）

把手机 / Pad / 电脑截图里的错题批量录入网站错题本。与网站「我的错题本」共用同一套数据（`wrong_questions` 表）。

## ⚡ 一键全自动（推荐用法）

**手机拍完 → 自动识别草稿 → GPT独立解题 + 原图/裁图逐题核验 → 仅通过题可同步**。强审核版本为 `gpt-import-review-1`；发现修订时必须人工明确确认，再由GPT审核最终版本，不能人工直接放行。失败、待补录和未确认修订均保留浏览器本机 IndexedDB 草稿，含原图和裁图，不会随批量导入清空。

强审核固定使用 `gpt-6.1-sol`，91token优先、UGQ保底，不回退GLM。默认同步线上时由网站托管鉴权并真实调用，审核记录保存在网站数据库；同步本机网站时仅在运行时读取本机 Zcode/Codex 安全配置，不把密钥写入项目、审核记录或exe。

- 缩略图右上角 **⚡**：自动处理这一张（AI 找出页面里每道题，各自裁剪）
- **「⚡ 全自动处理全部」**：批量处理已扫描的全部图片
- 手机上传面板勾选 **「上传后自动识别整理」**（默认开）：手机拍完传上来，电脑端 6 秒内自动开始处理
- 「仅自动上传GPT审核通过题」（默认开）：只提交持有服务端真实通过凭据的题；关掉则手动确认上传。清单显示逐题结论、原因和审核覆盖数，其余题不会隐式提交。

### 同步到哪本错题本

网站默认目标是 **`https://123-56-217-104.sslip.io:8090`**（可在「连接设置」改）。

- **不登录也能同步**：工具会自动用访客身份写入，数据进的是网站那本**家庭共享错题本**
- 登录家庭账号（sunny / mom / dad 任一）：AI 次数记在你自己账上，同步结果里也会记是谁录的
- 填 `http://127.0.0.1:8011` 则只进本机数据库（调试用）

> 网站侧：`wrong_questions` 的所有行归属统一为 `u_family`，任何账号（含游客）打开「错题本」看到的是同一本；谁录入、谁重做清零，全家同步可见。想恢复按账号隔离，服务端设 `LEARN_WB_SHARED=0` 即可。

AI 返回每题的题干、选项、正确答案、逐步推导、错因，以及题目在图中的位置（自动裁剪成单题配图）。

### 题型与拆分（v21 起）

- 一页多题会被**按题号逐题拆开**（第 13、14 题不会合并），一页最多 12 道
- 每题带 `qtype`：`choice` 单选 / `multi_choice` 多选 / `fill` 填空 / `solution` 解答；多选答案为完整 `answer_indices` 集合，缺答案不默认为A。
- 填空题不编造选项；选择题缺选项保留缺陷交GPT判定待补录，不靠降级填空绕过审核。
- 若模型只返回一道题，通常是提示词被弱化——本工具的 `AUTO_PROMPT` 已强制「页面上有几道返回几道」

### AI 通道优先级（本地优先，网站兜底）

| 顺序 | 通道 | 说明 |
|---|---|---|
| 1 | 「连接设置」里的本地 AI 端点 | 你自配的 OpenAI 兼容视觉接口 |
| 2 | **WorkBuddy 本地网关**（自动发现） | 读取 `~/.workbuddy/models.json`，自动挑可用视觉模型；可用环境变量 `WB_LOCAL_AI_MODEL` 指定模型 |
| 3 | 网站站内 AI | 前两者都连不上时兜底：识别 + 解题分析（占网站每日限额） |

实际用哪条通道，处理完会在按钮旁显示（如「WorkBuddy 本地 AI」）。

## 手机拍照上传（免微信传文件）

录入工具启动后监听局域网，工具首页顶部会显示 **局域网地址 + 二维码**：

1. 手机连同一个 WiFi，扫码或输入 `http://<电脑IP>:8021/m`
2. 手机页「📷 打开相机拍照」或从相册选择 → 自动压缩上传到电脑
3. 回到电脑工具首页「📱 手机拍照上传」面板，点图片 → 走原有裁剪 → AI 识别 → 错因 → 导入流程

说明：
- 上传的图片暂存在 `tools/wrongbook_tool/mobile_uploads/`，处理完可点「删除」清理
- 需要电脑与手机在同一 WiFi；工具没有鉴权，仅建议家庭局域网使用
- 「一键启动.exe」无需重新打包即可获得此功能（exe 只负责拉起 `server.py`）

## 一键启动（推荐）

双击仓库根目录的 **`错题本一键启动.exe`**：自动启动网站(:8011) + 录入工具(:8021) 并打开浏览器，关掉窗口即全部停止。已在运行的端口会自动跳过，不会重复拉起。

exe 由 `tools/wrongbook_tool/launcher.py` 打包而来，改过代码后重新打包：

```bash
.venv/Scripts/pyinstaller --onefile --distpath . --workpath build --specpath build --name "错题本一键启动" tools/wrongbook_tool/launcher.py
```

不想用 exe 也可以手动启动：

```bash
cd learning_highschool
.venv/Scripts/python.exe tools/wrongbook_tool/server.py
# 浏览器打开 http://127.0.0.1:8021
```

## 本机 AI 覆盖远端 AI

在「连接设置」里配置**本地 AI 端点**（OpenAI 兼容视觉接口，如 Qwen-VL / GLM-4V）后：

- **题目识别**走本地端点（优先于网站站内 AI 通道）
- **「🤖 本地 AI 补全解析」**：编辑题时一键独立解题，自动填入正确答案、解析、逐步推导、错因提示——全部走本机 AI，**不占网站每日 AI 限额**，网站 AI 未配置也能得到完整解析
- 未配置本地端点时自动回退到网站站内 AI 通道

## 使用流程

1. **连接设置**（右上角 ⚙️）：网站地址默认已是线上地址，可直接用；想记 AI 次数/署名就填账号密码登录（不登录会自动用访客身份同步）。
   - 可选：配置自定义 OpenAI 兼容视觉端点（如 Qwen-VL / GLM-4V），配置后识别优先走它；不配置则走 WorkBuddy 本地网关 → 网站站内 AI 兜底。
2. **扫描文件夹**：把手机/PAD/电脑截图放到一个文件夹（支持子文件夹递归），填路径点「扫描」。自动按**图片内容 md5 去重**，同一张截图复制多份只算一张。
3. **裁剪 + 识别**：点缩略图 → 在图上拖框选一道完整题目 → 「AI 识别」自动转录题干与选项（识别失败也可手工录入）。
4. **补错因**：核对题干/选项，选**我的错选**与**正确答案**，选学科+章节（运动学、力学、机械能、热力学、电路、电磁学等），记「为什么会错」和「正确解法推导」→ 加入待导入清单。
5. 逐题GPT审核：必须同时提供原图和裁图，服务器调用 `/api/v1/wrongbook/import/review` 签发数据库记录ID。修订须确认并再次审核；题干、选项、答案、解析、推导、分类、图片及范围的任一变更均使旧凭据失效。
6. 仅上传通过题：`/api/v1/wrongbook/import` 和服务层共同验证审核记录归属、内容/原图/裁图哈希、模型、版本及图片实际字节。伪造 `approved=true` 或 JSON 不生效；相同题干仍自动去重。旧拍照人工保存接口仅进入待审核区，不作为正式答案放行。

导入后打开网站「错题本」：按 `📥 学科 · 章节` 分组，可逐题看配图/错因/推导，也能重做清零；**全家人登录任何账号看到的都是同一本**。

## 文件说明

| 文件 | 作用 |
|---|---|
| `launcher.py` | 一键启动器源码（打包成仓库根的 `错题本一键启动.exe`） |
| `server.py` | 本地 FastAPI 服务（8021）：扫描/图片预览/AI 识别代理/导入代理 |
| `static/index.html` + `app.js` | 工具界面（无构建链，改完刷新即生效） |
| `config.json` | 运行后自动生成：网站地址、登录 token、本地 AI 端点（**只存本机**，部署脚本会排除） |

## 安全边界

- 图片预览只允许访问**已扫描目录**下的文件（防路径穿越）。
- 识别端点配置与登录token沿用本机配置；强审核凭证仅运行时读取安全配置或由网站托管，绝不打包。
- 审核必须把题目原图/裁图发送到配置的GPT服务商，非离线模型。自定义/WorkBuddy识别仅生成草稿，不授予正式入库权限。
- 信任边界是受信任的网站进程及其数据库；有服务器root/任意SQL写权限的人仍能故意绕过，不能声称防御root。exe仅是项目启动器，需与项目文件及 `.venv` 一起使用，启动时拒绝复用旧版服务。

## 分类体系

学科 / 章节定义在网站 `content/wrongbook_taxonomy.json`，网站与工具共用；要新增章节直接改该文件，无需重启（有缓存则重启网站）。
