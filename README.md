# 高中理科学习助手

面向高中生的物理 / 化学 / 数学微学习网站。每天 20–30 分钟精炼一个小主题，六大版块闯关，积分签到 + 名人卡收集。

- 部署目标：阿里云轻量 `123.56.217.104`，独立端口 **8090**（与同机 Hugo 博客隔离）
- 技术栈：FastAPI + SQLite / 原生 ES Modules（无构建链）
- 完整设计见 [实施计划.md](实施计划.md)
